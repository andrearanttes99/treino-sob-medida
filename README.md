# Treino Sob Medida

App web instalável (PWA) que monta treino de musculação, esporte e alimentação a partir do perfil de cada pessoa, com registro de treinos, peso, medidas e fotos de evolução.

- Funciona no celular e no computador, inclusive sem internet depois de instalado.
- Vários perfis no mesmo aparelho; os dados e as fotos ficam salvos só no aparelho.
- Publicado pelo GitHub Pages: https://andrearanttes99.github.io/treino-sob-medida/

As estimativas usam fórmulas padrão (IMC, Mifflin-St Jeor) e não substituem médico, nutricionista ou professor de educação física.

Veja [COMO-INSTALAR.md](COMO-INSTALAR.md) para instalar no celular.
