# Como colocar o Treino Sob Medida no celular

## 1. Publicar (grátis, uns 2 minutos)
1. No computador, descompacte `treino-sob-medida.zip`.
2. Abra https://app.netlify.com/drop e arraste a pasta `treino-sob-medida` para a página.
3. Crie a conta gratuita quando pedir. O Netlify gera um link `https://<nome>.netlify.app`.

O app precisa estar num endereço https para poder ser instalado. Qualquer hospedagem estática serve (Netlify, Vercel, GitHub Pages).

## 2. Instalar
- **Android (Chrome):** abra o link e toque em "Instalar app" ou ⋮ > "Adicionar à tela inicial".
- **iPhone (Safari):** abra o link, toque em Compartilhar > "Adicionar à Tela de Início".

Depois de instalado, o app abre em tela cheia e funciona sem internet.

## 3. Lojas (opcional)
- **Google Play:** gere o pacote Android em https://www.pwabuilder.com a partir do link publicado. É preciso uma conta de desenvolvedor Google Play (taxa única de US$ 25).
- **App Store:** o PWABuilder também gera o projeto iOS, mas é preciso um Mac com Xcode e uma conta Apple Developer (US$ 99 por ano).

## Observação
Os dados (perfis, treinos e peso) ficam salvos no aparelho de cada pessoa. Login e sincronização entre aparelhos exigiriam um servidor.
